# AI Job Market Analysis

## What this project does
Analysed a real dataset of 2000 AI job listings across multiple countries
to find salary trends, in-demand skills, and job opportunities.

## Key Findings
- AI Engineer is the most common AI role in India
- Average AI Engineer salary in India is $37,221
- PyTorch and SQL are the most in-demand skills
- Python is the 3rd most important skill for AI roles

## Tools Used
- Python
- Pandas (data analysis)
- Matplotlib (charts)

## Files
- `analysis.py` — main analysis code
- `ai_job_market_dataset.csv` — dataset used
